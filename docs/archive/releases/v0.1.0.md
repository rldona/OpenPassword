# OpenPassword 0.1.0

First release: offline Android password manager, with a vault encrypted by `op-core` (Rust).

## What's new

es-ES (`fastlane/metadata/android/es-ES/changelogs/1.txt`):

> Primera versión: baúl cifrado sin conexión, huella, autorrelleno y guardado de logins, TOTP con lector de QR, salud del baúl, copia automática cifrada, kit de emergencia e importación desde KeePass, 1Password, Bitwarden y CSV.

en-US (`fastlane/metadata/android/en-US/changelogs/1.txt`):

> First release: offline encrypted vault, fingerprint unlock, autofill and login saving, TOTP with QR scanner, vault health, automatic encrypted backup, emergency kit and import from KeePass, 1Password, Bitwarden and CSV.

## ⚠️ Notice: no external audit

This release **has not undergone an external security audit**. **Do not store real data** (passwords, keys or seed phrases you actually use). More information and how to report vulnerabilities: [`SECURITY.md`](../../../SECURITY.md)).
